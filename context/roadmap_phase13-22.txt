Recommended Development Order
I would not give Cursor the entire roadmap and tell it to implement everything. That will produce a large amount of coupled code and make debugging difficult.
Instead, we should work in these concrete milestones:
Milestone	Deliverable
M0	Foundation cleanup
M1	Drizzle + DB
M2	Auth + OTP
M3	Users + devices
M4	Direct chat
M5	Text messaging
M6	WebSocket realtime
M7	Offline sync
M8	Delivery/read reliability
M9	Groups
M10	Broadcast Lists
M11	Media
M12	Voice messages
M13	Push notifications
M14	Presence + typing
M15	Advanced messages
M16	Privacy + account
M17	E2EE
M18	Search
M19	Testing/security
M20	Performance
M21	AWS staging
M22	Production


The first implementation milestone should be M1: Drizzle + Database.
At the end of M1, we should have:
React Native app
       │
       │
       ▼
Fastify backend
       │
       ▼
Drizzle ORM
       │
       ▼
PostgreSQL 17
       │
       └── Migration 001

Then M2 can build authentication on top of a stable database layer.
This order keeps the system incremental and gives us a clean testable checkpoint after every major subsystem.
